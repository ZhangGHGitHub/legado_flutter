这是重构前 Android Beta 的只读 UI 参考截图。

- 设备：`emulator-5558` / `25098PN5AC`
- 分辨率：`720 x 1280`
- Android：`9 / API 28`
- 包名：`io.legado.app.releaseS`
- 采集日期：`2026-07-31`
- 当前主题模式：跟随系统；截图中的棕色顶栏、红色选中态和浅紫色内容面板属于当前主题配置，不是固定色值。

## Screenshot Groups

- `01`-`04`：首次启动隐私协议、更新日志、本地密码提示、书架空态。
- `05`-`11`：书架、发现、订阅主入口，以及书架菜单、书架搜索、发现筛选。
- `14`-`26`：订阅主界面、收藏空态、订阅源筛选/管理、“我的”主界面和滚动设置区。
- `27`-`30`：主题模式、主题设置、其它设置及滚动内容。
- `31`-`34`：WebDAV 帮助、备份配置页及其输入对话框状态。
- `38`-`39`：书源管理首次帮助和书源管理列表空态。
- `40`-`41`：规则订阅空态和新建规则订阅对话框。
- `50`-`53`：导入书源后的“我的”、书源管理列表、源规则帮助和书源编辑器。
- `54`-`59`：导入书源后的发现页、源分类展开、搜索状态、分类查询结果。
- `60`-`62`：书籍详情、详情滚动内容和目录章节列表。
- `63`-`67`：阅读器首次点击区域设置、阅读收据、正文页、阅读帮助文档。
- `68`-`70`：加入书架确认、加入书架后的书籍详情和书架数据态。
- `71`-`72`：书架搜索输入/历史和搜索结果数据态。

`12`、`13`、`18`、`19`、`20`、`31`、`32`、`35`、`36`、`37` 是导航过程中的过渡/回退状态记录；后续对照优先使用同组中明确命名的最终页面截图。

截图用于 UI 结构、状态、交互入口和主题映射对照。不要将空数据、首次启动提示或当前时间状态直接当作产品固定文案；行为验收仍以原版源码、契约测试和设备测试为准。

## Populated-State Notes

- `54-current-state.png` 是重新打开应用后的导航检查点，书架当时仍为空；它不是正式页面编号，可用于复现本轮采集起点。
- `54`-`72` 使用设备上已导入的 `新御书屋(千夜)` 书源，并在采集过程中查询分类 `都市言情`。
- `60`-`70` 使用查询结果中的《让你御兽，你去御女帝？》；阅读器正文已经加载真实章节内容，书架截图中的章节位置和最新章节来自设备当时的运行状态。
- `71`-`72` 使用设备已有的搜索历史 `重生之`；中文文本直接注入未成功，因此没有把失败的输入尝试当作结果，正式搜索结果来自已有历史项。
